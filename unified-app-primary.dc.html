What changed from Nav B
  • Search tab now opens with a full-width, 56px hero search bar (Direction 1's language) instead of a compact sidebar field — the same tab structure, but Search unmistakably reads as the default action.
  • "Dual Search" → "PSOC + PSIC"; "Correspondence" → "Compare Editions" — both in the tab bar and in every reference elsewhere in the app.
  • RM remains a full, equal tab for V1, unchanged in weight from Direction 2.
  • Two "Ask RM" positions are reserved (Search detail panel, Compare Editions detail panel) as dashed, non-interactive placeholders — no border fill, no cursor, no link semantics — so nothing clickable-looking ships unwired. Layout space holds until a later milestone wires the real control.
  • Browse/Archive stays folded into Search (edition radio group + level select + blank-query browse) — no separate top-level destination was added for it.
Notes for implementation
  • Renaming tabs is presentation-only — `main_nav` values (`"dual_search"`, `"correspondence"`) don't need to change, only the visible `tabPanel` titles.
  • The hero search bar is still the same `classification_query` input — only its size and position on the Search tab move.
  • "Ask RM about this" needs no new stable ID today; when wired, it should call the RM module's existing composer-set + `main_nav` tab-switch, not a new mechanism.
